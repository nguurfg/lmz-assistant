关于存档

该游戏的进度完全保存在浏览器 localStorage，不上传服务器，也没有云同步。 这意味着：清理浏览器数据、换浏览器、换手机都会丢失进度。 建议每隔一段时间在菜单里点一次「导出存档」保存 JSON 文件。

恢复存档

  • 在旧设备菜单点「导出存档」，得到 lmz-save-xxxx.json
  • 把文件传到新设备
  • 在新设备菜单点「导入存档」，选择该文件

常见问题

点了齿轮没反应？

该按钮在游戏内是动态渲染的，需等游戏主界面完全加载（进度 100%）后再点。 脚本每 250ms 会自动把按钮置顶并挂载监听。

换游戏后打不开？

打开菜单 → 「游戏地址」→ 点「设置」→ 粘贴该游戏的页面地址。 脚本会优先使用你填写的地址。

提示「未找到存档」？

说明该浏览器还没玩过这个游戏。先正常玩一次生成存档，再使用修改功能。

修改后没生效？

修改写入的是 localStorage，需要刷新页面才会被游戏重新读取。

想完全恢复原状？

  1. 在扩展面板中禁用或删除本脚本
  2. 如需恢复进度：菜单 →「恢复备份」（前提是之前点过「备份当前」）
  3. 最彻底：清除该站点的浏览器数据

技术原理（简版）

脚本分三个部分运行：

  1. 存储层：游戏把进度写在 localStorage 的几个固定 key 下 （主存档、关卡进度、副存档）。脚本直接读写这些 JSON 结构。
  2. 广告层：游戏的激励视频只有一个入口函数，且只在收到特定状态码时才发奖。 替换该函数即可实现"跳过广告仍拿到奖励"。
  3. 主站层：233 站点在未登录时会用登录框覆盖游戏区域， 移除该覆盖层并重新注入游戏 iframe 即可。
