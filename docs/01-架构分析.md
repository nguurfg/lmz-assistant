# 01 · 架构分析

## 整体链路

```
233 乐园主站（Nuxt 3 SSR）
  www.233leyuan.com/mini-game        游戏列表
  www.233leyuan.com/game-detail-h5/{id}   详情页（「开始游戏」按钮）
  www.233leyuan.com/h5/{id}          ★ 游戏运行页
        │
        │ 内嵌 iframe（未登录时被登录框覆盖）
        ▼
  游戏本体（Laya 2.13.0 + 自研 bundle）
        h5.metaapp.cn/online/h5/{appId}/{version}/index.html
```

## 站点技术栈

| 层 | 技术 |
|---|---|
| 主站 | Nuxt 3（SPA + SSR），构建产物在 `_nuxt/` |
| 登录 SDK | 自研 `metaappLoginSdk`，走 `oauth.ark.online` iframe |
| 游戏引擎 | Laya 2.13.0（Layabox） |
| 游戏逻辑 | 单文件 `bundle.js`（约 2.8 MB，强混淆） |
| 资源 | 散文件形式（`.atlas` + 合并 `.png`），由 `fileconfig.json` 索引 |

## 主站关键节点

| 选择器 | 含义 |
|---|---|
| `.find-game-list__card-link` | 游戏列表卡片 |
| `a.gd-h5-start` | 「开始游戏」按钮 |
| `.online-game-runner` | 游戏运行容器 |
| `.online-game-runner__gate` | 登录遮罩（显示「正在打开登录...」） |
| `#sdkIframe` | 登录 SDK iframe（`oauth.ark.online/login`） |
| `.no-login` | 右上角游客头像占位（32×32，非弹窗） |
| `topBox / settingBtn` | 游戏内左上角齿轮按钮（菜单入口挂载点） |

## 游戏内部结构

Laya 场景树（实测节点名）：

```
stage
└── root
    └── StartGame (场景)
        ├── topBox          ← 顶部栏
        │   ├── fragment     皮肤碎片计数
        │   ├── gold         金币
        │   ├── settingBtn   ★ 原生齿轮
        │   └── soundBtn     音效
        ├── ...（模式入口：ghostBtn / coupleBtn / nightmareBtn / puppetBtn / plotBtn / cannodieBtn）
        └── ...（功能：StartBtn / Shop / rankBtn / bulletinBoardBtn / gift_btn / skinGameConsole）
```

## 资源组织

```
gameAssets/asset/
├── Main.json                     主场景
├── config/*.json                 gameConfig / gameLevData / trollLevData / prefabResConfigPath
├── data/*.json                   config / equipmentData / mapsData
├── Prefabs/**/*.json             各 UI 面板
├── UIJson/Dialogs/*.json         弹窗
└── res/atlas/*.atlas + 同名 .png  图集描述 + 合并图
res/sound/*.mp3                  音效
res/Skeleton/**/*.sk             骨骼动画
```

★ 图集内的子图**没有独立文件**，全部合并进同名 `.png`。
