# 03 · 存档结构

## 结论：纯单机，无云端

| 项 | 实测值 |
|---|---|
| 后端调用 | **仅 1 个接口** `GET /api/v2/sys/server/time`（服务器时间校准） |
| 上传接口 | **无** |
| 身份标识 | URL 参数 / Cookie / `window.openId` 全为空 |
| 数据位置 | 全部在浏览器 `localStorage` |
| 是否需账号 | **不需要**（233 会给访客自动分配 uid） |

> `cloudData` 这个 key 名字有误导性 —— 它就是 localStorage 里的普通键，存关卡进度，从未上传。

## localStorage 键一览

| 键 | 内容 |
|---|---|
| `PlayerDataItem` | 主存档（金币 / 皮肤 / 模式 / 战绩 / 蓝图 / 统计） |
| `cloudData` | 关卡进度（当前关卡、周上限、上周最高、胜负标记） |
| `_save_{id}` | 副存档（每个玩法一套） |
| `playGameCount` | 游戏次数 |

## 主存档字段（PlayerDataItem）

### 货币与统计
```
_gold          金币
_fragment      皮肤碎片
_goldenKey     黄金钥匙
_mw            ?
_win / _lose   胜场 / 负场
_mvp           MVP 次数
_isNewPlayer   新手标记（置 0 可跳过引导）
```

### 模式解锁（6 个）
```
_isUnlockGhostMode     猎梦者
_isUnlockPuppetMode    伥鬼/傀儡
_isUnlockPlotMode      剧情
_isUnlockCoupleMode    情侣
_isUnlockNightmare     噩梦
_isUnlockCanNoDie      不死
```

### 皮肤
```jsonc
_skinSelectIndex      [["sunxiaomei", 1], ...]     // [皮肤ID, 装备态]
_skinFragment         [["sunxiaomei", 碎片数], ...]  // ★改这里加碎片
_unlockSkinFragment   [["sunxiaomei", 持有, 已解锁, 门槛1, 0, 门槛2, 0, 门槛3, 0]]
_trollSkin            { mg_0..mg_6 }               // 鬼皮肤解锁位
_skinTreasureChestIndex  皮肤扭蛋机次数
```
6 个玩家皮肤：`sunxiaomei` / `wangxiaoming` / `liujisheng` / `lixiaodai` /
`wangxiaohua` / `guolaosi`

> ★ 注意：`_skinSelectIndex` 的第二个值是**装备态**，
> 真正的「是否解锁」在 `_unlockSkinFragment[r][2]`。

### 建筑蓝图（16 项）
```
spell ice entrapment barb guillotine repair energyhood smoney
longrange particlea solenoid doorLevUp dice meow splitter troll
```

### 地图进度
```jsonc
_plotInfo     剧情地图 [mapId, 名称, ?, ?, 解锁等级, 通关]
_normalInfo   经典地图
_trollInfo    猎梦者地图
_puppetInfo   伥鬼地图
_coupleInfo   情侣地图
```

### 关卡进度（cloudData）
```
currGameLev / lastGameLev / floorGameLev / maxGameLevThisWeek
curTrollLev / lastTrollLev / floorTrollLev / maxTrollLevThisWeek
isOpenGameLev / iscanopenGamelev / isLastGameWin / isLastTrollWin
```

## 副存档（_save_*）
```
Money / goldMoneyNum / moneyNum   各类货币
physicalNum                        体力
unlockedfood / itemIds / petIds   已解锁内容
unlockedfood  ["101","106","201","301","401","402","403"]
```

## 存档风险

进度**只在本机浏览器**，没有云同步。以下操作会丢失：
- 清理浏览器数据 / 缓存
- 换浏览器或设备
- 使用无痕模式

建议定期用脚本内置的「导出存档」保存 JSON。
