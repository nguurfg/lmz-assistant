# 05 · 脚本迭代史

记录游戏内菜单入口的 8 次迭代 —— 同一目标，每次失败原因都不同，
对后续处理 Laya / Canvas 类游戏有参考价值。

| 版本 | 做法 | 结果与原因 |
|---|---|---|
| v4.1 | 在游戏自带 `settingBtn` 上再挂一个 `click` | ❌ 变成两个监听，游戏原版先执行 → 弹「网络出错」 |
| v4.3 | 覆写按钮的 `hitTest` | ❌ 该按钮类**没有** `hitTest` 方法，覆写完全无效 |
| v4.4 | 自绘 CSS 齿轮图标 | ⚠️ 能用，但与游戏视觉不统一 |
| v4.5 | 透明覆盖层 + `preventDefault` | ❌ `preventDefault` 阻止了 `click` 生成 → 点不动 |
| v4.6 | 覆写 `btn.on` 堵住游戏再挂监听 | ❌ 破坏游戏自身逻辑 → **整页卡死** |
| v4.7 | 透明层放进 `layaContainer` | ❌ Laya 自有 DIV 层消费触摸 → 真机到不了 |
| v4.8 | `document` 捕获阶段监听 + 坐标判定 | ❌ 合成事件通过，真机仍无反应 |
| **v4.9** | **直接在按钮上挂 `mousedown`** | ✅ **可用** |

## 最终方案要点

```js
// 关键：Laya.Event.MOUSE_DOWN === 'mousedown'（小写 d）
var ev = gear._events || gear._$events;
ev.click = [];                        // 清空游戏原版监听，避免网络请求
ev.mousedown.push({ runWith: openPanel });
```

配合两个持续生效的守护：

```js
// 1) 按钮每帧被游戏设回隐藏 → 定时恢复
setInterval(function () {
  if (!gear.visible) gear.visible = true;
  top.setChildIndex(gear, top.numChildren - 1);  // 提到最上层
}, 250);
```

```js
// 2) 广告函数由 bundle 在运行时创建 → 需守护 setter
Object.defineProperty(window, 'Platform', {
  get: function () { return _plat; },
  set: function (v) { _plat = v; patch(v.playVideo); }
});
```

## 方法论沉淀

1. **不要改游戏对象的方法**（`on` / `hitTest`），只改其 `_events` 数据
2. **合成事件能过不代表真机可用** —— 必须了解宿主的真实事件消费链
3. **运行时创建的对象要用 setter 守护**，否则补丁会被覆盖
4. **每次失败都记录根因**，避免在同一处重复试错
