# 04 · 踩坑记录

按「症状 → 根因 → 修法」记录，便于复现时快速定位。

---

## 静态求值类

### 1. 解密成功数为 0，且无任何报错
**症状**：`调用点求值: 尝试 5361 成功 0`
**根因**：解密器单独加载，抛 `ReferenceError: _0x453d is not defined`，
被 `try/catch` 静默吞掉。
**修法**：把字符串表函数拼在解密器代码之前一起 `new Function`。

### 2. 调用点一个都匹配不上
**症状**：`尝试 0`
**根因**：正则只匹配数字参数，而 RC4 的 key 常是**字符串字面量**。
**修法**：参数正则改为 `(?:(-?\d+)|"([^"]*)"|'([^']*)')`，并按 3 个捕获组一组取值。

### 3. 包装函数匹配数为 0
**症状**：`包装函数: 0`
**根因**：正则假定标识符形如 `_0x` + 纯十六进制，但实际存在 `_0x43ec`（含数字 `3`）。
另外合成测试样本时，包装体末尾多写了分号（`return X(a);}` 而非 `return X(a)}`）也会失配。

## 浏览器注入类

### 4. 菜单入口点击无反应
**根因**：`Laya.Event.MOUSE_DOWN` 的实际值是字符串 `'mousedown'`（**小写 d**）。
写成 `'MOUSE_DOWN'` 会挂不上去。
**修法**：用常量或小写字面量。

### 5. 点了按钮弹出「网络出错」
**根因**：按钮是游戏自带的，原版 click 会请求服务器。
**修法**：清空原有 click 监听（`_events.click = []`）再挂自己的。

### 6. 覆写按钮的 `on` 方法导致页面卡死
**症状**：整页无响应。
**根因**：游戏自身逻辑也依赖 `btn.on`，被覆盖后事件链断裂。
**修法**：不要覆写游戏对象方法，只改 `_events`。

### 7. 覆写 `hitTest` 无效
**根因**：该按钮类**根本没有 `hitTest` 方法**（`b.hitTest is not a function`），
Laya 2.x 用 `hitTestPoint` / skin 透明区判定。
**修法**：走事件挂载，不要改命中逻辑。

### 8. 透明覆盖层收不到真机触摸
**症状**：合成 `pointerdown` 事件能触发，真机点击无反应。
**根因**：`layaContainer` 内除画布外还有一个无 id 的 DIV，Laya 在其上消费触摸。
**修法**：放弃覆盖层，直接在游戏节点上挂事件。

### 9. `preventDefault()` 导致点不动
**根因**：阻止了浏览器后续生成 `click`。
**修法**：只监听 `pointerdown` / `mousedown`，且不调用 `preventDefault`。

## 环境类

### 10. hook `Storage.prototype.setItem` 导致脚本回路死锁
**症状**：页面无响应，调试工具调用超时。
**根因**：游戏高频写档，hook 内部再触发写档形成递归。
**修法**：改用低频轮询比对，或干脆不 hook。

### 11. `getBoundingClientRect()` / `getComputedStyle()` 调用超时
**症状**：调试工具返回 `no return value`。
**根因**：该 WebView 环境对强制同步布局支持不佳。
**修法**：改用 `offsetLeft` / `offsetTop` / `clientWidth` 等属性读取。

### 12. proot 沙盒内后台进程被杀
**症状**：`nohup` / `setsid` 启动的服务无响应。
**根因**：每次工具调用结束会终止所有子进程。
**修法**：改用前台分批执行，或把服务放到设备侧运行。

## 工程习惯

### 13. 「以为写进去了」其实没写
**症状**：声称已加入某段逻辑，实际文件里没有。
**根因**：只在运行时设了变量就当作改了文件。
**修法**：每次改文件后用 `grep` 复核关键标识符确实存在。

### 14. 依赖文件的工具跨环境不可用
**症状**：沙盒无法读取手机侧 `/storage/emulated/0/...`。
**修法**：内容通过 MCP 工具读写，不假设沙盒能直接访问。
