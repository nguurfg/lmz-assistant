# 猎梦者助手 · lmz-assistant

面向 233 乐园在线小游戏（`h5.metaapp.cn`）的**浏览器用户脚本**，配套本仓库的分析文档与自研工具。

> ⚠️ **本仓库不包含任何游戏源码或美术/音频素材。**
> 游戏本体代码与素材的著作权属于原开发者，本仓库仅包含自主编写的脚本、分析文档与分析工具。

---

## 这个脚本能做什么

| 功能 | 说明 |
|---|---|
| 免登录直玩 | 移除 233 站点的登录弹窗与「正在打开登录…」遮罩，自动注入带游客身份的游戏 iframe |
| 免激励视频 | 拦截广告请求并直接发放奖励，可在菜单内一键开关 |
| 游戏内菜单 | 挂载到游戏左上角**原生齿轮按钮**，点击打开 |
| 数值修改 | 金币、皮肤碎片、黄金钥匙、战绩、关卡进度 |
| 解锁内容 | 6 个模式、6 个玩家皮肤 + 7 个鬼皮肤、16 项建筑蓝图、8 张剧情地图 |
| 存档管理 | 导出 / 导入 JSON 存档，本地快照备份与恢复 |

**全部逻辑在浏览器本地运行，不读取、不上传任何个人数据。**

打开 **`web/index.html`**（GitHub Pages 上即为仓库首页），

## 工具：static-solve.js

针对 `obfuscator.io` 风格的「字符串表 + RC4/Base64 解密器」混淆方案，
**只做静态求值，不执行任何业务代码**。

```bash
node tools/static-solve.js <input.js> [-o out.js] [--json strings.json]
```

工作原理：

1. 抽出字符串表函数 `_0x453d()`（返回字符串数组）
2. 抽出解密函数 `_0x1464(idx,key)`（RC4）与 `_0x43ec(idx,key)`（Base64）
   —— **必须与字符串表一起加载**，否则解密全部失败
3. 抽出所有二级包装函数 `function _0xXXXX(a,b,c,d,e){return _0xNNNN(算式,参数)}`
4. 解析每个包装的「索引参数位置 / 密钥参数位置 / 偏移量」
5. 扫描全文调用点求值并替换为字符串字面量

在目标样本（2.8 MB）上的实测结果：

```
[+] 字符串表长度: 33594
[+] 解密器: _0x1464, _0x43ec
[+] 包装函数: 1511 可解析: 1509
[+] 调用点求值: 尝试 5361 成功 5361
[+] 已替换 5361
```

运行自测（不需要任何游戏文件）：

```bash
node tools/selftest.js     # -> [selftest] PASS
```
